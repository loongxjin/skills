# Foresee 推理链示例参考

这里给出推理链的标准格式与三个经典示例。**重点是格式与反思深度，不要照搬结论。**

每一步必须包含四要素：**支撑 / 前提 / 反问 / 信心**。其中"前提"和"反问"是防自嗨的核心：
- 前提 = 这条规律生效需要满足什么条件；不满足，这一步就是薄弱环节，得在信心评估里点名
- 反问 = 对立规律为什么不适用 + 具名的对冲力量（呼应五大校验②，不要用抽象规律名敷衍）

---

## 标准格式

```
### 链 A：[趋势名] — [标题] | [分析维度] | [趋势加速/方向改变]
- 反共识度：★★★☆☆ | 综合信心：65%

趋势：[一句话，世界正朝什么方向变。是对格局走向的判断，不是"谁受益"]

① 事件 → 直接推论
   支撑：[事实 / 规律编号]
   前提：[规律生效条件。不满足 = 薄弱环节]
   反问：[对立规律为何不适用 + 具名对冲力量]
   信心：⭐⭐⭐ (3/5)

② 推论 → 二阶后果
   支撑：...
   前提：...
   反问：...
   信心：⭐⭐ (2/5)

③ 二阶后果 → 三阶影响
   ...（3-5 步，每步用 → 推进）

📊 结论：[从趋势推导出的可操作判断]
可能错在哪：[1-2 句，指名最易断裂的那一步]
标的：→ 标的表第 N 项
```

## 示例 1：中国 2030 载人登月（完整示范四要素）

```
### 链 A：航天技术从军用向民用扩散 — 登月催化民用化 | 技术维度 | 趋势加速
- 反共识度：★★☆☆☆ | 综合信心：70%

趋势：国家级航天工程会沿着"军用→科研→工业→民用"的路径持续向外扩散技术红利

① 登月计划推进 → 国家航天预算台阶式上升
   支撑：事实——载人登月已写入国家规划，预算公开数据
   前提：财政空间不收缩、计划不因外部冲击延期
   反问：若经济下行压力加大，航天是否被"挤预算"？——对冲：地方专项债+军民融合资金已分流承担
   信心：⭐⭐⭐⭐⭐ (5/5)

② 预算上升 → 航天技术向民用外溢加速
   支撑：规律 L02（技术扩散路径可预测）
   前提：存在承接转化的民用产业（卫星互联网、新材料、精准定位）
   反问：技术外溢周期长，A股主题炒作往往先于业绩 3-5 年——对冲：估值提前透支后回调
   信心：⭐⭐⭐⭐ (4/5)

③ 民用外溢 + 大众关注度上升 → FOMO 资金涌入航天主题
   支撑：规律 H01（FOMO）、H02（从众）
   前提：出现全民级催化事件（试飞直播、发射成功）
   反问：FOMO 是双刃剑——推高也意味着追高风险，物极必反（P01）会反向作用
   信心：⭐⭐⭐ (3/5)

📊 结论：航天主题在中长期（2026-2029）有结构性机会，但短期易被事件情绪放大
可能错在哪：第 ③ 步——FOMO 的时机最难把握，容易"逻辑对、买点错"
标的：→ 标的表
```

**要点：** 每一步都有依据。第 ① 步是公开事实（信心最高）；第 ② 步套技术扩散规律，但前提（民用产业承接）需要验证；第 ③ 步套从众心理，信心最低——因为情绪传导最不确定，且自带反向力量。

## 示例 2：疫情放开（短期高确定性链）

```
### 链 A：防控成本见顶 → 必然放开 — 短期需求链 | 社会维度 | 方向改变
- 反共识度：★☆☆☆☆ | 综合信心：85%

趋势：防控的经济社会成本已逼近系统承受极限，方向必然反转

① 防控成本无限增大 → 系统承压到极限
   支撑：事实——民生数据、地方财政、供应链中断记录
   前提：无更强力的外部理由维持原政策
   反问：安全考量是否会压过经济考量？——对冲：经济失速本身也会动摇安全基础
   信心：⭐⭐⭐⭐⭐ (5/5)

② 物极必反 → 放开
   支撑：规律 P01（物极必反）
   前提：决策机制对成本信号有响应
   反问：若决策响应滞后，"极"会被推得更远才反转——但方向不变
   信心：⭐⭐⭐⭐⭐ (5/5)

③ 放开 → 短期感冒药/退烧药需求暴增
   支撑：规律 E01（供需关系）+ H02（恐慌性购买）
   前提：放开节奏快、人群免疫屏障低
   反问：产能能否快速跟上平抑需求？——对冲：药企扩产需要 2-3 个月，短期缺口真实存在
   信心：⭐⭐⭐⭐ (4/5)

📊 结论：放开后 1-3 个月，相关药品公司业绩确定性暴增
可能错在哪：第 ③ 步的"短期"窗口很窄，业绩兑现后股价往往提前回落（提前计价）
标的：→ 标的表
```

**要点：** 短期链确定性高，前三步信心都在 4-5 分。但正因为确定性高，**提前计价风险也最大**——人人都能想到的逻辑，往往在业绩出来前就被炒完。这就是为什么标的表的"剩余空间"列必须结合提前计价检查。

## 示例 3：反共识链怎么写

对同一个事件（登月），反共识链不是"为了反而反"，而是**换一个分析维度**看同一个事件：

```
### 链 B：航天虹吸资源 → 其他科技承压 — 资源分配链 | 经济维度 | 方向改变
- 反共识度：★★★★☆ | 综合信心：45%

趋势：国家级航天工程会在中短期虹吸有限的科研资金与高端人才

① 登月预算上升 → 航天领域集中吸纳资金与人才
   支撑：事实——高端科研人才总量有限、财政有上限
   前提：人才/资金市场不能无限扩张、存在挤出效应
   反问：是否可以通过引进海外人才补缺口？——对冲：地缘紧张期高端人才流入受限
   信心：⭐⭐⭐⭐ (4/5)

② 资源集中 → 非航天科技领域短期承压
   支撑：规律 E02（边际效用递减）、资源挤出效应
   前提：挤出效应大于增量资金的总盘子扩张
   反问：若国家同时扩大整体科研投入，挤出可能被稀释——这是本链最大弱点
   信心：⭐⭐ (2/5)

③ 航天概念股若过度炒作 → 泡沫破裂反向大跌
   支撑：规律 P01（物极必反）
   前提：炒作幅度显著超过业绩兑现节奏
   反问：若业绩真的兑现（如卫星互联网商用），泡沫可能被消化而非破裂
   信心：⭐⭐⭐ (3/5)

📊 结论：在航天主题被热炒的中后期，做空过度炒作标的（谨慎）或配置被挤出的科技板块，可能与链 A 相反的收益
可能错在哪：第 ② 步——挤出效应是否真实存在，高度依赖整体科研预算的总盘子
标的：→ 标的表
```

**要点：** 反共识链的关键在于"换维度"——链 A 从技术扩散看（看多航天），链 B 从资源分配看（看空或看其他）。两条链可以同时存在于一份报告里，互为对冲。反共识度标 ★★★★ 是因为"航天热炒时看空航天"明显与大众相反。

## 常见错误对照

| 错误写法 | 问题 | 正确写法 |
|---------|------|---------|
| `支撑：这是必然趋势` | "必然"不是依据 | `支撑：规律 L01 + 事实 [具体数据]` |
| `前提：宏观环境稳定` | 太抽象，无法判断是否满足 | `前提：美联储不重启加息（当前市场预期 0 次加息）` |
| `反问：也可能不涨` | 没有具名对冲力量 | `反问：$120 油价触发需求毁灭，航空物流需求骤降反噬（对冲②）` |
| `信心：高` | 主观随意 | `信心：⭐⭐⭐ (3/5)` + 在薄弱步骤主动降分 |
| 趋势写成 `买半导体设备股` | 这是结论不是趋势 | 趋势：`AI 利润正从设计层向设备/材料层扩散` |
