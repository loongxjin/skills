# Foresee 推理链示例参考

这里包含设计文档中的三个经典推理链示例。在做预测时参考这些示例的推理深度和格式，但不要照搬结论。

---

## 示例1：中国2030登月

```
结构性事件：中国宣布2030年载人登月计划
规律匹配：FOMO、国家叙事效应、历史类比（美国登月）

推理链：
  登月计划推进
  → 航天产业投资增加（事实：国家预算公开）
  → 航天技术民用化加速（规律：技术扩散）
  → 大众关注度上升（规律：国家叙事→民族自豪感）
  → FOMO资金涌入航天主题（规律：从众效应）
  → 航天相关股票上涨

标的：A股航天概念股
时机：2026-2029年分批关注，关键节点（试飞、发射）前6-12个月
```

**分析要点：** 这条链的每一步都有明确的依据。"登月计划推进"是公开事实，"投资增加"有预算数据支撑，"技术民用化"套用技术扩散规律。最后两步套用从众效应和FOMO，这是事件对市场情绪的传导路径。

## 示例2：台湾统一

```
结构性事件：中美实力此消彼长，台湾问题最终会解决
规律匹配：霸权更替周期、矛盾推动发展、博弈论

推理链：
  中美实力差距缩小（事实：GDP、军事数据）
  → 美国干预意愿和能力下降（规律：成本收益分析）
  → 统一概率上升（规律：矛盾推动发展）
  → 统一相关产业受益（基建、军工、物流）
  → 相关股票上涨

标的：A股军工/基建/福建本地股
时机：长周期，关注关键政治事件窗口
```

**分析要点：** 这是一个长期推理链。关键在第一步的"事实"是否成立——需要引用具体的GDP数据和军力对比数据。第二步的逻辑链条较长，信心分应该偏低。

## 示例3：疫情放开

```
结构性事件：2022年防控已到执行不下去的地步
规律匹配：物极必反、群体心理、供需关系

推理链：
  防控成本无限增大，社会承受力到极限（事实：民生数据）
  → 物极必反，必然放开（规律：物极必反）
  → 放开后短期内感冒药需求暴增（规律：供需关系+恐慌性购买）
  → 相关药品公司业绩暴增
  → 相关股票上涨

标的：A股感冒药/中成药公司
时机：放开政策信号出现后立即
```

**分析要点：** 这是一个短期推理链，确定性相对较高。"防控成本"有具体民生数据支撑，"必然放开"套用物极必反。第三步是最确定的——供需关系 + 恐慌性购买是经典组合。

## 反共识链示例

对上述事件，一条反共识链可能是：

```
事件：中国2030登月计划
反共识链（从大众"航天股涨"的反方向思考）：
  登月计划推进
  → 航天领域人才和资金高度集中（事实：预算有限）
  → 其他科技领域资源被挤占（规律：边际效用递减）
  → 非航天类科技公司短期承压
  → 如果航天概念股过度炒作，泡沫破裂后反而大跌（规律：物极必反）

标的：做空过度炒作的航天概念股（谨慎）
```

**分析要点：** 反共识链不是"为了反而反"，而是换一个维度看同一个事件。这条链从资源分配的角度看，得出的结论与主流相反。反共识度标注为 ★★★★☆。
