# 常见事件类型的传导范式库

这个文件收录常见事件类型的**传导链范式**和**历史上预期差错位的环节**。用途：Step 1（传导链推演）时查阅，避免遗漏关键节点。

它不是照搬的模板——每次事件的具体背景都不同。把它当作"检查清单"，确认你的传导链覆盖了这类事件常见的传导路径，然后结合本次事件的具体情况调整。

## 怎么用

1. 先按 SKILL.md 的 Step 0、Step 1 做自己的传导链推演。
2. 查下面有没有匹配的事件类型。
3. 对照范式，检查自己有没有漏掉关键节点，尤其是二阶、三阶的远端影响。
4. 重点看每节末尾的「预期差错位点」——那是历史上 alpha 常出现、但市场常反应不足的地方。

---

## 1. 货币政策（降息 / 加息 / QE / QT）

**一阶（多为 beta）：**
- 降息 → 利率敏感资产估值抬升（成长股、科技、地产、黄金）
- 加息 → 估值压缩，资金从风险资产流向无风险资产
- 降息 → 美元走弱（通常）、非美货币走强

**二阶（alpha 高发）：**
- 降息 → 套息交易（carry trade）平仓 → 日元、低息货币升值；新兴市场资金回流
- 降息 → 收益率曲线陡峭化 / 倒挂修复 → 银行 NIM（净息差）变化（方向取决于长端）
- 超预期降息 → 市场解读为"经济有问题" → 避险情绪上升 → 黄金、长债、VIX
- 加息周期末段 → 高杠杆主体（小盘股、REITs、部分新兴市场）承压

**三阶：**
- 大幅宽松 → 后续通胀反复 → 商品、黄金二次走强
- 持续宽松 → 资产泡沫 → 远端波动率上升
- 政策转向 → 跨资产相关性突变 → 风险平仓潮

**预期差错位点：**
- 市场常线性外推"降息=利好股市"，但**预防式降息 vs 衰退式降息**结果完全不同。衰退式降息往往伴随盈利下修，股市可能先跌。
- "**降息幅度 vs 市场预期**"比"降不降息"更重要。已 price in 的降息落地反而是利多出尽。
- **幅度的质变**：25bp 是常规节奏，50bp 及以上属"非标准幅度"，更易触发"美联储看到衰退信号"的避险解读路径，也更易引发利多出尽。分析 50bp 时，务必把"衰退解读"这条二阶路径权重调高。
- 加息末段的**盈利韧性**常被低估（市场过度悲观）。

## 2. 财政 / 产业政策（刺激 / 减税 / 行业支持）

**一阶：**
- 行业支持政策 → 直接受益板块（补贴、准入、采购）
- 减税 → 相关行业利润率改善
- 大规模财政刺激 → 相关产业链订单

**二阶：**
- 产业政策 → **供应链**（上游材料、设备、核心零部件）往往比终端更受益（"卖铲人"逻辑）
- 补贴政策 → 产能扩张 → **后续过剩与洗牌风险**（光伏、新能源车的历史教训）
- 减税/刺激 → 财政赤字扩大 → 长端利率、本币汇率压力
- 政策支持 → 银行信贷倾斜 → 相关 ABS、信用债

**三阶：**
- 产业政策退出 / 补贴退坡 → 龙头受益（洗牌后集中度提升），尾部企业出清
- 地方财政压力 → 城投债、地方国企的信用分化

**预期差错位点：**
- A 股题材炒作常**抢跑过度**：政策刚提"研究/支持"就炒到位，正式落地反而出货。注意区分"概念期"和"业绩兑现期"。
- **"卖铲人"（设备/材料供应商）的弹性常被低估**，因为市场盯着终端品牌。
- 补贴退坡后的**龙头集中**逻辑，是中线 alpha 常出现的地方。

---

## 3. 地缘冲突

**一阶：**
- 冲突 → 避险资产（黄金、美债、美元、瑞郎）走强
- 涉及产油国/产区 → 原油、天然气、相关农产品跳涨
- 军工股脉冲

**二阶：**
- 能源价格飙升 → 通胀预期上升 → 央行政策两难（滞胀风险）
- 制裁 → 替代供应国受益（如俄气断供后的 LNG、美国油气）
- 航运受阻 → 运价、航运股、替代路线（如苏伊士受阻后的好望角）
- 冲突地区资金外流 → 周边市场/避险市场承接

**三阶：**
- 长期冲突 → 国防开支全球提升 → 军工产业链中线景气
- 能源/粮食安全焦虑 → 各国加码能源转型、粮食储备 → 新能源、农业
- 制裁金融化（SWIFT、外汇储备）→ 去美元化叙事、黄金、加密货币

**预期差错位点：**
- 地缘事件的**首次冲击往往是过度反应**，随后回补。短线交易和长线配置逻辑要分开。
- **"谁填补缺口"**的替代供应商，alpha 常比直接的军工脉冲更持久。
- 去美元化/黄金叙事是**慢变量**，别当成短线催化剂用。

## 4. 科技突破（AI / 芯片 / 新药 / 新能源技术）

**一阶：**
- 直接技术受益者（芯片厂商、药企、技术拥有方）
- 相关指数/ETF（纳斯达克、半导体、生物科技）

**二阶：**
- **算力/基础设施**（电力、散热、数据中心、光模块、HBM）——"卖铲人"，弹性常超一阶
- **上游材料与设备**（晶圆、特种气体、制药 CDMO、试剂）
- **应用层**（能立刻把新技术变现的下游：广告、SaaS、垂直应用）
- 新药 → 医保支付、流通、冷链、伴随诊断

**三阶：**
- 技术普及 → **电力/能源缺口**（AI→电力是典型，已多次验证）
- 技术替代 → **被颠覆者的价值毁灭**（传统媒体被 AI 内容冲击、燃油车被新能源替代）——做空/低配也是 alpha
- 人才/专利争夺 → 相关高校、科研服务、知识产权

**预期差错位点：**
- 市场常**过度关注"明星公司"，低估基础设施层**的确定性（电力、散热、连接——这些需求无论谁赢都要买）。
- **"电力"是 AI 时代最容易被反复低估的二阶链**，历史上多次在行情中段才被定价。
- 新药/新技术的**适应症扩展**和**海外授权**是中线超预期常见来源。
- 别忘了**做空侧**：被颠覆的旧势力，alpha 不只在多头。

---

## 5. 监管（行业整顿 / 松绑）

**一阶：**
- 整顿 → 相关行业估值杀跌（中概股、教培、互联网平台、游戏、医疗）
- 松绑 → 估值修复

**二阶：**
- 监管不确定性 → 全行业折价（不只被监管者，也包括上下游、关联行业）
- 整顿 → **集中度提升**（小玩家退出，龙头反而中长期受益）——这是监管后段的重要 alpha
- 数据/金融监管 → 合规服务商、网络安全、监管科技受益

**三阶：**
- 监管常态化 → 估值体系重建（从"成长股"估值切换到"公用事业/基础设施"估值）
- 跨境监管（如中概股退市风险）→ 港股承接、A 股替代上市

**预期差错位点：**
- 监管冲击的**恐慌底**常过度。政策底（表态缓和）往往领先业绩底和股价底。
- **"监管出清后的龙头"**是中线 alpha 的经典来源——但需要确认是"真出清"而非"持续不确定"。
- 政策**松绑的方向**常被低估其持续性，市场线性外推"还会继续收紧"。

---

## 6. 黑天鹅（违约 / 制裁 / 爆仓 / 系统性风险）

**一阶：**
- 事件主体直接崩跌（违约企业、爆仓交易所、受制裁主体）
- 流动性冲击 → 全资产相关性趋近 1，普跌

**二阶：**
- 交易对手风险 → 谁持有事件主体的敞口？（银行、基金、保险公司）
- 抵押品连锁 → 抵押品贬值引发追加保证金 → 进一步抛售（convexity 卖出）
- 监管救市/干预 → 流动性注入、做空限制、撮合并购

**三阶：**
- 信任危机 → 资金从该类资产/机构永久性流出（FTX 后加密资金流向、硅谷银行后小银行存款流出）
- 监管收紧 → 行业格局重塑
- "火灾出售" → 被错杀的优质资产，是抄底 alpha 的来源

**预期差错位点：**
- 黑天鹅初期的**流动性冲击会误伤优质资产**，区分"基本面受损"和"单纯被抛售"——后者是 alpha。
- **"谁接盘"**（白衣骑士、并购方）和**"谁被资金重新青睐"**（避险替代、竞争对手）常在一周后才被定价。
- 系统性危机中，**央行/政府的反应速度**决定二阶传导是否被切断——这是最大的不确定性，别假装能预测。

## 7. 0→1 早期产业（低空经济 / 人形机器人 / 合成生物 / 商业航天 / 脑机接口）

这类事件介于"产业政策"和"科技突破"之间，但有自己独特的传导节奏：技术还在 demo/试点阶段，商业模式未跑通，政策是主要驱动力。典型特征是**估值完全靠远期愿景贴现，业绩兑现遥远**。

**一阶（最拥挤，纯概念）：**
- 整机/核心产品厂商（eVTOL、机器人本体、合成生物菌株）→ 政策定调即炒估值
- 概念股 / 主题 ETF → 资金涌入，常抢跑过度

**二阶（alpha 高发，"卖铲人"+ 基础设施）：**
- **准入/认证/安全**环节（适航认证、安全评估、检测）← 这是 0→1 产业的"总开关"，产品要卖必须先过这关，确定性最高但市场盯得少
- **核心上游材料/零部件**（碳纤维、减速器、电机、传感器）← 减重/性能刚需，卖铲人弹性常被低估
- **基础设施**（空管系统、低空通信、充电/起降场、训练设施）← 商业化前置条件，先于终端放量

**三阶（决定生死的变量）：**
- **监管-技术混合节点**（空域改革、路权、伦理审查、临床审批）← 决定整个产业能否从 demo 走到规模化，市场常线性假设它会顺利，这是最大的预期差错位点
- **政府/地方买单能力**（基建订单真实性依赖财政）← 财政紧张时订单打折
- **死亡谷**（从 demo 到规模化订单的跨越）← 多数 0→1 产业死在这里
- **安全事故黑天鹅**（坠机、故障伤人）→ 全行业监管收紧 + 估值杀 + 商业化推迟，产业独有尾部风险

**预期差错位点：**
- **A 股题材炒作在"概念期"最疯狂**，但真正的 alpha 常在"准入/认证/安全"和"卖铲人上游"这些不被 glamorous 关注的环节。
- **"能否拿到规模化订单"** 是 0→1 产业的生死线，市场线性外推"政策支持=订单会来"，但空域/路权/审批/财政任一卡壳都会让逻辑证伪——把证伪条件设在这些卡点上。
- **补贴退坡后的龙头集中**（参照光伏、新能源车历史）是中线 alpha 经典来源，但需要等"退坡"信号出现，别在概念期就埋伏。
- **做空侧**：概念期抢跑过度的整机/概念股，在业绩兑现期（往往 2-3 年后）大概率均值回归——"做多卖铲人 + 远离/做空最拥挤整机"是比单边做多更稳的结构。

---

## 使用提醒

- 范式是"地图"，不是"实景"。每次事件都要结合当时的市场环境、估值水位、持仓结构做调整。
- 预期差错位点是基于历史的归纳，**这次可能不一样**——但知道历史规律，至少能让你问出对的问题。
- 如果遇到的事件类型不在上面（比如罕见的宏观拐点、全新的技术范式），就靠 Step 1 的方法论（跨资产、分层级推演）自己搭传导链，这也是这个 skill 训练的核心能力。
