## EV 计算

| 项目 | 数值 | 依据 |
|------|------|------|
| 赢的概率 | 65% | 基础率：... + 微调：... |
| 赢的幅度 | +30% | 剩余空间：... |
| 输的概率 | 35% | = 1 − 赢的概率 |
| 输的幅度（常态） | −15% | 历史回撤：... |
| 输的幅度（极端） | −50% | 胖尾填充 |
| **EV（常态）** | **+14%** | (0.65×30%) − (0.35×15%) |
| **EV（极端）** | **+2%** | (0.65×30%) − (0.35×50%) |
| 无风险利率 | ~2.5% | 机会成本基准 |
| **判定** | **值得做 / 不值得** | EV > 无风险利率？敏感性稳健？胖尾检验通过？ |

**敏感性：** 概率/幅度 ±10~20% 扰动后 EV 是否仍为正。

## 仓位

| 项目 | 数值 | 依据 |
|------|------|------|
| 凯利参考 | f* = 317% → 半凯利 158%（不约束） | EV 14% ÷ (30%×15%)；输赢幅度接近时凯利虚高 |
| 可承受最大亏损 | 总资金 5% | 出局线：... |
| 该标的最坏跌幅 | −50% | 关卡一极端值 |
| 不出局上限 | 10% | 5% ÷ 50% |
| **建议仓位** | **10%** | min(半凯利 158%, 上限 10%, 杠铃剩余) |
| 杠铃检查 | ✅ 冒险端合计 10% ≤ 15% | 已有投机仓：... |
| 尾部压力测试 | 最坏总亏损 12% | 含已有持仓，≤ 出局线 |

## 交易计划表

| 项目 | 规则 | 挂钩对象 |
|------|------|---------|
| 入场 | 现价/回踩价位、分批计划 | 当前价 |
| 止损 | 价格 + 触发后动作（清仓/减半） | 证伪条件——信号触发即走，不等价格 |
| 目标 | 分批止盈价位 | 催化剂兑现 + 剩余空间 |
| 时间止损 | N 天/周未兑现就撤 | 催化剂时间窗口 |
| 加仓 | 什么条件出现才加、加到多少 | 传导链验证信号 |
| 减仓 | 什么条件出现减多少 | 定价程度变化 |
