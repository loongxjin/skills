# Trade Planner — 期望值与仓位规划

## 灵魂

> **EV 是决策的唯一长期准绳。** 决策质量 ≠ 结果质量：亏钱可能只是走了不幸路径，赚钱也可能是运气。只有 EV 能区分。**EV 不抵无风险利率（~2.5%）→ 不做**——正 EV 不抵国债，不值得占仓。

> **世界是胖尾的，输的幅度必须用极端值填一次。** 只填"正常回撤"会让负期望看起来像正期望——散户亏损的最大单一心理原因。胖尾检验不过 → 不做。

> **仓位第一原则是不出局。** 亏 50% 需涨 100% 回本，亏 80% 需涨 400%。凯利给增长最优的上限，不出局给必须守住的底线，仓位取两者之低。

> **计划在买入前定好，到价机械执行。** 亏损时系统 1 接管，你不会理性。计划是写给买入后那个不理性的自己看的。

## 输入

消费 alpha-finder 报告的产出：alpha 方向、催化剂 + 时间窗口、证伪条件、剩余空间、信心度 x/5。**没有 alpha 报告也能用**——用户直接指定标的时，先快速补齐预期差 + 催化剂 + 证伪条件，标注"未走 alpha-finder 流程"。还需要的账户约束：当前价、可用资金、已有相关仓位、可承受总亏损。

## 三道关卡

每道关卡有完成标准。前关不过，后关不开。

### 关卡一 · EV —— 做不做

**概率校准**：从基础率起步（这类事件历史上兑现频率），按本次信息微调。反方证据写不出 → 概率虚，降档。

**幅度校准**：赢的幅度来自剩余空间（有依据，不是拍的目标价）。输的幅度算两个数——
- **常态回撤**：查该标的/板块历史，不许"感觉差不多"
- **极端值**：按胖尾假设填一次更狠的（−40% 起，高波动标的更高）

**EV 与判定**：
```
EV = (赢的概率 × 赢的幅度) − (输的概率 × 输的幅度)
```
- **敏感性**：概率、幅度各扰动 ±10~20%，EV 仍为正？只有一条窄路径为正 → 脆弱
- **胖尾检验**：用极端跌幅重算 EV，转负 → 不做
- **机会成本**：EV < ~2.5% 无风险利率 → 不做
- **Pre-mortem**：假设一年后亏了 50%，写出 3 个**可归因**原因（不是"市场不好"），哪条让你咯噔一下

**完成**：EV（常态 + 极端）数值 + 敏感性结论 + 与无风险利率比较 + 明确判定。判定"不值得"→ 直接输出"不做"结论（一句话 + EV 表 + 为什么），不进后续关卡。

### 关卡二 · 仓位 —— 下多大

两个来源取低者：**半凯利**（增长最优参考）与**不出局上限**（生存硬约束）。

**凯利参考**（只作参考上限）：
```
f* = EV ÷ (赢的幅度 × 输的幅度)
```
用常态幅度算，取**半凯利**（满凯利回撤太深，概率估计有偏时会系统性过度下注）。⚠️ **输赢幅度接近时 f* 会虚高甚至 >100%**（如 EV 2% ÷ 10%×10% = 200%）——此时凯利失效，不出局上限就是答案。凯利假设概率准确、结果二元、可无限重复，真实投资三条都不成立。

**不出局上限**（硬约束）：
```
单标的最大仓位 = 可承受最大亏损 ÷ 该标的最坏跌幅
```
可承受最大亏损默认总资金 5%~10%（对应"最坏总亏损 ≤ 20%"的出局线精神）；最坏跌幅用关卡一的极端值（如 −50%）。

**建议仓位 = min(半凯利, 不出局上限, 杠铃剩余)**。

- **杠铃检查**：所有投机性 alpha 仓位合计 ≤ 冒险端上限（默认 15%），安全端（现金/国债）不参与
- **伪分散检查**：同一驱动因子的多个标的合并为一个头寸算，不许重复占用风险预算
- **尾部压力测试**：最坏总亏损 = Σ(各仓位 × 最坏跌幅)，含已有持仓，是否仍不触出局线？

**完成**：三项数值齐备 + 杠铃/伪分散/尾部检查结论。

### 关卡三 · 计划 —— 怎么执行

把数字变成可执行规则。核心反默认原则：**止损挂钩证伪条件，不挂钩价格**——证伪信号触发即走，不等价格。

| 项目 | 挂钩对象 |
|------|---------|
| 入场 | 现价 / 回踩价位、分批计划 |
| 止损 | 证伪条件（信号触发即走）+ 触发后动作 |
| 目标 | 催化剂兑现 + 剩余空间，分批止盈 |
| 时间止损 | 催化剂时间窗口——窗口内未兑现即撤 |
| 加仓 / 减仓 | 传导链验证信号 / 定价程度变化 |

**完成**：表填齐，止损与证伪一一对应、目标与催化剂一一对应。填不出 → 回对应关卡补，不硬填。
