# Alpha Finder — 基于信息差的 alpha 发现

## 灵魂

> **1. Alpha 来自信息差，不来自更长的推理链。** 公开信息 + 公开规律 ≠ alpha。alpha 唯一来源是你看到的市场没看到、或看错了的东西。

> **2. 找 alpha 之前，先搞清楚市场已经知道了什么。** 不知道共识在哪，就没法判断什么是"预期差"。

> **3. "逻辑上受益"不等于"还能赚到钱"。** 已经涨了 50% 的"利好"可能已充分定价。

> **4. 找不到 alpha 就说找不到。** "此事件多为 beta，无明显预期差"是有信息量的结论。硬凑的 alpha 比没找到更危险。

## Alpha 的四个硬条件

每个候选 alpha 必须同时满足。缺一条就不是 alpha：

| # | 条件 | 检验 |
|---|------|------|
| 1 | **预期差存在** | 市场共识是什么？你的判断和共识的具体差异在哪？不能是"我觉得市场太乐观了"这种空话 |
| 2 | **信息或框架优势** | 你凭什么和市场共识不同？掌握了市场没注意的数据？用了不同框架？"想得更深"通常是幻觉 |
| 3 | **未被充分定价** | 相关资产体现了多少？还剩多少空间？ |
| 4 | **有催化剂** | 什么事件会在有限时间内迫使市场重新定价？没有催化剂，"低估"可以永远持续 |

## 市场效率认知

不同市场用公开信息找 alpha 的难度不同。任何市场只要事件有实质传导都可以分析，但在效率越高的市场，越要严格审视"为什么还没被定价"。

| 市场 | 公开信息找 alpha 难度 | 
|------|---------------------|
| **A 股**（题材/中小盘）| 相对容易——注意力不均、信息消化慢 |
| **加密货币**（山寨/链上）| 相对容易——信息极度分散、机构覆盖浅 |
| **港股** | 中等——流动性分化，小市值类似 A 股、大市值接近美股 |
| **商品/FX** | 中等——alpha 多在供需节奏的边际变化 |
| **美股**（大盘）| 难度高——高度有效，公开信息基本已定价。对"为什么还没被定价"的回答要格外过硬 |
| **债券** | 难度高——宏观驱动，定价效率高 |

## 流程

按 Step 0→8 顺序走。每步有完成标准。在关键节点简短报告进度。

### Step 0 · 事实校准 *（只收集，不分析）*

核实事件**真实性、时间、量级、官方口径**。**时间锚定**——事件当天 vs 三个月后，分析重点完全不同。搜不到可靠信源标注"事实存疑"。

**完成标准**：核心事实（带数字带时间）、距现在多久、市场是否有明确预期、事件类型。

### Step 1 · 画出市场共识地图 *（只画地图，不找 alpha）*

在找"市场哪里错了"之前，先搞清楚"市场现在怎么想"。

查阅 [`references/consensus-playbook.md`](references/consensus-playbook.md) —— 对照该事件类型，确认市场"标准 playbook"是什么。共识 playbook 里的一阶影响 = 大概率已定价。

**完成标准**：
1. 市场对这个事件的"标准解读"是什么？
2. 哪些资产已经发生了方向性移动？
3. 共识最依赖的关键假设是什么？（这个假设就是后续攻击的靶点）

### Step 2 · 反向证据搜索 *（只收集信息，不做推导）*

有了共识地图，找**市场没看到的东西**。回答三个问题：

1. "如果市场第一反应的结论是错的，最可能因为忽略了什么数据？"
2. "什么信号正在朝市场共识的反方向移动？"（已经在移动的，不是"可能会"的）
3. "当前主流叙事中，哪些信息被系统性省略或淡化？"

搜索方向：非共识数据（产业链上游订单 vs 终端销量、链上行为 vs 价格）、被忽视的关联方（卖铲人、替代品）、反向价格信号（一致看多但资金在流出）。

**完成标准**：一个"市场可能错了或漏了"的清单，每项有具体信号支撑。没找到则标注"未发现显著信息差"。

### Step 3 · 传导链推演 *（不做定价判断，不落标的）*

用共识地图（Step 1）和信息差清单（Step 2）**交叉定位**：

- **一阶**（直接受益/受损）= 共识 playbook 内容 → **大概率已定价，beta 为主**
- **二阶、三阶** = 市场注意力覆盖不到的地方 → **alpha 潜在区域**
- 传导节点同时出现在 Step 2 信息差清单里的 → **最高优先级 alpha 候选**

**完成标准**：至少到二阶，关键链到三阶。每个节点标注方向 + 逻辑 + 是否在共识 playbook 内 + 是否有反向证据支撑。

### Step 4 · 定价程度 + 为什么还没被定价 *（只判断空间，不判断方向）*

两个问题一起回答：

**定价程度**——相关资产已涨/跌了多少？估值/持仓处于什么分位？剩余空间多大？标注：已充分定价 / 部分定价 / 基本未定价。无法获取数据则标"数据不足"，alpha 信心降档。

**为什么还没被定价？**——这是整个流程最关键的检验。必须命中至少一条合法答案：

| 合法答案 | 解释 |
|---------|------|
| **注意力偏差** | 市场焦点在别处，忽略了这里——所有人盯龙头，没看上游卖铲人 |
| **信息分散** | 关键信息存在但不被主流覆盖——链上数据早于价格，但分析师不看 |
| **框架差异** | 你用了市场不常用的分析框架——从"空域审批"而非"政策口号"看产业 |
| **结构性约束** | 主流资金因规则无法参与——小市值不被机构覆盖 |
| **激励不对称** | 卖方/媒体有动机不讲某个角度——投行不 cover 做空标的 |

**不合法答案**（出现则不是 alpha）："市场不理性"、"我研究得更深"、"历史的必然"。

**完成标准**：每个 alpha 候选标注定价程度 + 剩余空间 + 为什么还没被定价（类型 + 解释）。答不出的降级为非 alpha。

### Step 5 · 证伪条件与催化剂 *（不给仓位，不给目标价）*

**证伪条件（三级检验点）**每个检验点必须有：时间窗口 + 可量化阈值 + 触发后的判断。不可量化的证伪条件（如"市场风格变了"、"情绪转差"）不写入报告。

- **即时检验（1-3天）**：市场是否认可这个逻辑？最短平快的检验信号。
  - 例："次日板块涨幅 <2% 且缩量 → 市场不认可此逻辑，降级观察"
  - 例："24h 内相关标的无明显方向性移动 → 事件冲击力低于预期，alpha 存疑"

- **短期检验（1-4周）**：传导链的第一环是否如期启动？
  - 例："两周内未见政策细则落地 → 催化节奏慢于预期，时间窗口后移"
  - 例："相关公司未在互动平台/调研中提及该事件影响 → 传导链可能不成立"

- **中期检验（1-3月）**：核心假设是否兑现？这是最终判断 alpha 真伪的检验。
  - 例："标的 Q2 财报订单未体现传导 → 传导链断裂，逻辑证伪"
  - 例："三个月后相关资产定价程度无明显变化 → '为什么还没被定价'的回答有误"

**催化剂**：什么事件/数据/节点会迫使市场重新定价？大概什么时间？
**时间维度**：短线事件驱动 / 中线趋势

**完成标准**：每个 alpha 方向配齐三级检验点（即时 + 短期 + 中期）+ 催化剂 + 时间窗口。

### Step 6 · 标的落地 *（不给仓位，不给目标价）*

把 alpha 方向落到具体标的。排序依据：**弹性 × 剩余空间**（不是弹性单排。高弹性但已充分定价 ≠ alpha）。区分龙头和二线。

**完成标准**：表格呈现。每个标的标注：对应哪条预期差、弹性来源（业绩/估值/概念）、定价程度、证伪条件。超过 3 个标的时检查是否存在伪分散（不同标的实则同一驱动因子）。

```markdown

> **报告日期：** YYYY-MM-DD

> ⚠️ 非投资建议，仅供研究参考。

## 一句话
（核心判断，3行内。找不到 alpha 就写"此事件多为 beta"——这就是结论。）
```

## 信心度

| 分 | 含义 | 条件 |
|----|------|------|
| **5** | 高度确信 | 事实核实 + 预期差清晰有数据 + 定价程度可判断 + 催化剂明确 |
| **4** | 较有把握 | 事实核实，预期差清晰但部分依赖推断 |
| **3** | 方向可参考 | 预期差存在但定价数据不足，或"为什么没被定价"回答不够硬 |
| **2** | 框架性分析 | 事实部分存疑，或信息差来源较弱 |
| **1** | 高度不确定 | 事实存疑/传闻/无可信信息差来源 |

**不能打 5 分：** 定价数据缺失、"为什么没被定价"答不出、事实存疑——任中一条封顶 3 分。

## 工具失效时

核心能力在分析框架。数据缺失时诚实面对：事实/定价部分标"数据不足"，信心封顶 3 分，不给剩余空间判断。报告顶部数据状态字段如实标注。不给仓位和目标价——本来就如此。

---

## 原则

- **信息差是 alpha 的唯一来源。** 不能说清楚"凭什么和市场共识不同"，就没有 alpha。
- **诚实优于好看。** "没找到 alpha"是有信息量的输出。
- **少即是多。** 一个扎实的 alpha 方向胜过十个 beta 罗列。
- **证伪先于信仰。** 没有可观测证伪条件的想法不写进报告。
