# 市场共识地图

这个文件收录常见事件类型的**市场标准反应**——即市场"第一反应"是什么、共识依赖什么假设、共识在历史上最常在什么地方出错。

**这不是 alpha 地图。** 这里列出的"一阶反应"大概率已被定价。它的作用是：**在找 alpha 之前，先确认你知道了市场已经知道的东西**——然后去共识覆盖不到的地方找 alpha。

## 怎么用（用于 Step 1）

1. 确定事件类型，找对应条目
2. 对照"市场标准反应"——这就是当前市场的共识基线
3. 看"共识最脆弱的假设"——这是后续反向证据搜索的重点攻击靶点
4. 看"历史常被忽略的环节"——这里常有信息差，但**需要结合本次事件的具体数据验证**，不是照搬

## 1. 货币政策（降息 / 加息）

**市场标准反应：**
- 降息 → 利好成长股/科技/黄金/地产、利空美元
- 加息 → 利空风险资产、利好银行净息差（短端）
- 市场第一时间按"降息幅度 vs 预期"交易——超预期降息 = 短期利好

**共识最脆弱的假设：**
- "降息 = 利好股市"。这忽略了**预防式降息 vs 衰退式降息**的根本差异。衰退式降息伴随盈利下修，股市可能先跌
- 50bp 以上的"非标准幅度"更易触发"美联储看到了我们没看到的衰退信号"的避险解读——这个路径市场反应往往滞后

**历史常被忽略的环节：**
- 降息 → 套息交易平仓 → 日元/低息货币升值、新兴市场资金流动——这个传导链在大众叙事中几乎不被提及，但体量巨大
- 加息周期末段，市场过度悲观时，**盈利韧性**常被低估
- 大幅宽松 → 后续通胀反复 → 商品/黄金二次走强——这是三阶传导，市场在降息初期几乎不交易这个

**一阶已定价信号：** CME FedWatch 概率、利率期货定价、近期成长股相对价值股的涨幅

## 2. 财政 / 产业政策

**市场标准反应：**
- 政策支持 → 直接利好相关板块（补贴受益方、准入放开方）
- A 股特色：政策刚提"研究/支持"就炒，正式落地反而出货
- 市场按"政策力度 × 覆盖范围"线性推算受益程度

**共识最脆弱的假设：**
- "政策支持 = 业绩兑现"。A 股题材常抢跑过度——概念期的估值扩张和业绩兑现期的盈利增长是两回事
- "补贴 = 利好"。忽略了补贴退坡后的**产能过剩与洗牌**——光伏、新能源车的历史教训反复验证

**历史常被忽略的环节：**
- **"卖铲人"（上游设备/材料/核心零部件）——政策驱动的产业链中，上游的确定性和弹性常被低估，因为市场注意力盯在终端品牌上
- 补贴退坡后的**龙头集中**逻辑——洗牌期龙头受益、尾部出清，这是中线 alpha 经典来源
- 地方财政压力 → 城投/地方国企信用分化——宏观→微观的次生传导

**一阶已定价信号：** 政策宣布后相关板块涨幅、媒体覆盖密度、研报数量激增

---

## 3. 地缘冲突

**市场标准反应：**
- 冲突爆发 → 避险资产跳涨（黄金、美债、美元）、军工脉冲、产油国/产区受波及则原油跳涨
- 市场的第一反应几乎总是**过度反应**——首次冲击后往往回补

**共识最脆弱的假设：**
- "冲突 = 持续避险"。忽略了冲突的节奏——高强度爆发后迅速转入停火谈判是常见模式（参考 2026 年美伊案例）
- "油价涨 = 通胀失控 = 美联储崩溃"。忽略了需求毁灭、SPR 释放、OPEC+ 增产等系统自愈机制

**历史常被忽略的环节：**
- **"谁填补缺口"**——替代供应商（如俄气断供后的美国 LNG、挪威）的 alpha 常比直接军工脉冲更持久
- 制裁金融化 → 去美元化叙事 → 黄金/加密——这是慢变量，不适合短线交易但适合中线配置
- 航运受阻 → 运价脉冲 → 替代路线受益——次生传导，市场关注度低

**一阶已定价信号：** 冲突爆发后黄金/原油的日内涨幅、VIX 跳升幅度、军工股涨幅

---

## 4. 科技突破（AI / 芯片 / 新药 / 新能源）

**市场标准反应：**
- 技术突破 → 直接受益方（技术拥有者、芯片厂、药企）股价跳涨
- 市场注意力高度集中在"明星公司"——OpenAI 的合作方、新药的研发方
- A 股进一步表现：概念股全面跟涨，龙头和蹭概念的都涨

**共识最脆弱的假设：**
- "技术领先 = 商业成功"。技术可行性和商业规模化之间隔着巨大的鸿沟
- "先发者通吃"。科技史上先发者被后发者颠覆的案例远多于先发者持续领先的案例

**历史常被忽略的环节：**
- **基础设施层（电力、散热、数据中心、光模块、连接件）**——无论谁赢都需要的基础设施，确定性远高于押注某一家技术公司。AI 时代的"电力"是多轮行情中反复被低估的环节
- **上游"卖铲人"**（晶圆、特种气体、制药 CDMO、试剂）——弹性常超终端品牌
- **做空侧**——被新技术颠覆的旧势力，alpha 不只在多头
- 新药 → 医保支付、冷链、伴随诊断——二阶传导，市场关注度远低于药企本身

**一阶已定价信号：** 技术发布后核心标的涨幅、ETF 资金流入、媒体头条覆盖

---

## 5. 监管（整顿 / 松绑）

**市场标准反应：**
- 监管整顿 → 相关行业估值杀跌（教培、互联网平台、游戏、医疗的历史案例）
- 监管松绑 → 估值修复反弹
- 市场倾向于线性外推——整顿了就认为"还会继续收紧"，松绑了就认为"全面放开"

**共识最脆弱的假设：**
- "监管冲击 = 行业永久受损"。忽略了整顿后**龙头集中度提升**——小玩家退出，龙头中长期反而受益
- 政策底（表态缓和）、业绩底、股价底——三者时间差是 alpha 窗口

**历史常被忽略的环节：**
- **监管出清后的龙头**——整顿期被错杀、洗牌后集中度提升的标的，是中线 alpha 经典来源。但需要确认是"真出清"而非"持续不确定"
- **合规服务商**（数据安全、监管科技）——监管收紧的直接受益方，但市场关注度远低于被监管者
- 估值体系重建——从"成长股"切换到"基础设施/公用事业"的估值逻辑，这个切换过程存在预期差

**一阶已定价信号：** 监管消息后板块跌幅、政策关键词搜索热度、外资/北向资金撤离规模

---

## 6. 黑天鹅（违约 / 爆仓 / 系统性风险）

**市场标准反应：**
- 事件主体崩跌，全资产相关性趋近 1——流动性冲击下什么都跌
- 市场第一反应是**无差别抛售**，然后才开始区分"真受伤"和"被误伤"
- 恐慌期定价的是最坏情景

**共识最脆弱的假设：**
- "这次不一样 / 系统性崩盘"。大多数黑天鹅最终被政策干预或系统自愈消化。恐慌期的线性外推（"雷曼时刻"类比）通常过度
- 忽略了央行/政府反应速度——大规模冲击往往触发快速政策响应，切断传导链

**历史常被忽略的环节：**
- **被错杀的优质资产**——区分"基本面受损"和"单纯被流动性抛售"，后者是 alpha。恐慌期不看基本面的抛售创造了这种机会
- **"谁接盘"**——白衣骑士、并购方、被资金重新青睐的替代标的——这些信息的定价往往滞后一周以上
- 信任危机后的**资金永久性迁移**——FTX 后的加密资金流、硅谷银行后的小银行存款流出——这种结构性转移是中线 alpha

**一阶已定价信号：** 事件主体和相关板块跌幅、VIX/信用利差跳升幅度、交易所/平台资金净流出

---

## 7. 0→1 早期产业（低空经济 / 人形机器人 / 合成生物 / 商业航天）

**市场标准反应：**
- 政策定调 → 概念股全面炒作，整机/核心产品厂商最受追捧
- 估值完全靠远期愿景贴现，业绩兑现遥远
- A 股特色：概念期最疯狂，业绩兑现期（2-3 年后）大概率均值回归

**共识最脆弱的假设：**
- "政策支持 = 订单会来"。忽略了空域/路权/审批/伦理/财政的卡点。0→1 产业多数死在从 demo 到规模化订单的"死亡谷"
- 线性假设"政策推进顺利"——产业独有尾部风险（安全事故/黑天鹅）会导致全行业监管收紧 + 估值杀

**历史常被忽略的环节：**
- **准入/认证/安全环节**（适航认证、安全评估、检测）——0→1 产业的"总开关"。产品要卖必须先过这关——确定性最高，但市场盯得少（因为不够 glamorous）
- **核心上游材料/零部件**（碳纤维、减速器、电机、传感器）——卖铲人逻辑，弹性常被低估
- **做多卖铲人 + 远离最拥挤整机**——比单边做多更稳的结构
- 安全事故黑天鹅——产业独有风险，市场在炒作期几乎不定价

**一阶已定价信号：** 政策发布后概念股涨幅、媒体标题数量、散户讨论热度、主题 ETF 资金流入

## 使用提醒

- 这个文件告诉你**市场大概率已经知道了什么**。真正的 alpha 不在这个文件里——在共识覆盖不到的地方。
- "历史常被忽略的环节"是基于归纳——**这次可能不一样**。用它来引导搜索方向，而不是当作结论。
- 如果遇到上面没有的事件类型——用你自己的框架推演"市场第一反应会是什么"，然后用反向证据搜索去攻击它。
